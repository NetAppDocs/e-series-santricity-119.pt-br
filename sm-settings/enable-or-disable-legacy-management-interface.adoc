= Ativar ou desativar interface de gerenciamento legada no SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode ativar ou desativar a interface de gerenciamento legada (SYMbol), que é um método de comunicação entre o array de storage e o cliente de gerenciamento.

.Sobre esta tarefa
Por padrão, a interface de gerenciamento legada está ativada. Se você desabilitá-la, o array de storage e o cliente de gerenciamento usarão um método de comunicação mais seguro (API REST sobre https); no entanto, certas ferramentas e tarefas podem ser afetadas se ela for desabilitada.

[NOTE]
====
Para o sistema de storage EF600, este recurso está desativado por padrão.

====
A configuração afeta as operações da seguinte forma:

* *Ativado* (padrão) — Configuração necessária para configurar espelhamento com a CLI e algumas outras ferramentas, como o adaptador OCI.
* *Desativado* -- Configuração necessária para impor a confidencialidade nas comunicações entre o array de storage e o cliente de gerenciamento, e para acessar ferramentas externas. Configuração recomendada ao configurar um Directory Server (LDAP).


.Passos
. Selecione o menu: configurações [Sistema].
. Desça até *Configurações adicionais* e clique em *Alterar interface de gerenciamento*.
. Na caixa de diálogo, clique em *Yes* para continuar.
